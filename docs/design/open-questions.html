Open Questions

Unresolved design problems and test prompts.

Back to docs index

Question Why It Matters Next Test
What does the small compensation action do? Failed connections need compensation strong enough to soften misses without making failure optimal. Test resource gain, card draw, marker placement, and turn-order priority.
How often should self-connection reset cards? Played cards stay face up until self-connection, so reset frequency controls pacing and available targets. Track how many rounds players can act before needing to self-connect.
What does trading require and produce? Mutual player connections need a concrete payoff. Test free trade, forced one-for-one trade, and shared production.
What does an escalating factory run cost multiply? “Cost” may mean the dollar running cost alone or both that cost and the modules' resource inputs. Run the same three-factory engine under both interpretations and compare cost growth.
Who chooses factory run order, and when can outputs be reused? Factory order sets the 1×, 2×, and later costs, while immediate reuse could create production chains within one connection. Test fixed and player-chosen order with immediate and delayed output availability.
How does module ownership affect shared exoplanet factories? The rules mark module owners but do not say whether different owners may share a factory or which installed modules and outputs a connected player controls. Test owner-only operation against operation of the whole factory by the connected player.
When must a kept exoplanet module be constructed? The rules do not say whether kept modules can be held, whether discard picks count as drawn modules, or whether older modules can be constructed. Test immediate construction against a persistent module hand.
Is an empty factory slot already a factory? Factories require one or more modules, but the exoplanet setup also describes its three empty slots as empty factories. Choose one term for empty spaces and check whether any rules need factories to exist before installation.
What is in each exoplanet's module deck? Deck size and composition control access to new production and the value of spending more Teams. Build a small deck from duplicate starting modules before adding unique modules.
What is the core turn loop? The loop sets pacing, downtime, and player agency. Prototype a 20-minute loop with build, connect, score.
Are gates owned, shared, or both? Ownership controls player interaction and tension. Compare tolls against exclusive control.
What moves through the network? The answer determines theme, scoring, and components. Test goods, people, influence, and contracts.
How does the game end? The end trigger shapes tempo and risk taking. Try infrastructure limit and contract depletion triggers.
