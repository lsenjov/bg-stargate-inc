Design Principles

Rules for choosing between competing ideas.

Back to docs index

Principles

  1. Connection should create mutual pressure, not solitaire optimization.
  2. A player should understand why another player cares about a route.
  3. Board changes should stay legible at a glance.
  4. Scoring should reward timing and network shape, not only accumulation.
  5. Rules should be teachable from the table without hidden reference load.

Design Checks

  • Does this rule make the network more meaningful?
  • Does it create a decision before the obvious move?
  • Can a new player predict the consequence?
  • Does it reduce downtime?
