Card Type Purpose Count Status

Exoplanet Selection Targets an exoplanet in the middle for connection. One for each visible exoplanet in each player's set Draft
Pause Lets a player wait, see all non-pause choices, then choose any final target card from hand simultaneously with other pause players. The pause card and target card are both consumed. One per player Draft
Contract Gives players route or delivery goals. Unresolved Candidate
Module Lists a module's name, type, construction cost, running cost, optional inputs, and outputs. Ownership is set when the module is installed. Each player starts holding one of each of the six starting modules. Exoplanet decks and discards are currently empty. Draft
Upgrade Changes gate capacity, range, cost, or scoring. Unresolved Candidate
Event Changes network incentives or constraints. Unresolved Candidate
