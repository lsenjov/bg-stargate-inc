Glossary

Stable terms for rules and components.

Back to docs index

Term Working Meaning Status
Stargate A connection point or infrastructure piece used to link distant locations. Draft
Connection A usable link between two points in the network. Draft
Route A path through one or more connections. Draft
Network The full set of available stargates and connections. Draft
Contract A scoring or reward condition tied to specific connections or deliveries. Candidate
Exoplanet A middle target players can connect to during a connection selection round. Draft
Pause A selection card that lets a player wait until non-pause choices are visible before choosing any final target card from hand. Draft
Played Card A face-up selection card that cannot be played again until returned to hand. Draft
Failed Connection A connection attempt that does not create a connection after pause choices resolve. Draft
Small Action Compensation given to a player who failed to connect. Unresolved
Module A production component with a name, owner after installation, type, construction cost, running cost, optional inputs, and outputs. Draft
Factory Slot A place at a home planet or exoplanet where a module can be installed. Home planets have no slot limit; exoplanets start with three empty slots. Draft
Factory One or more modules of the same type stacked in installation order in a factory slot. Draft
Factory Type The module type shared by every module in a factory. Current types are Rural, Underground, and Industrial. Draft
Construction Cost The resources paid to install a module. Construction on an exoplanet also costs one Team. Draft
Running Cost The dollar cost printed on a module for running it. How factory cost escalation applies to this cost and inputs is unresolved. Draft
Input An optional resource requirement listed on a module for producing its outputs. Draft
Output A resource produced by a running module. Draft
Team A resource used to search exoplanet module decks or discards and to pay the additional construction cost on an exoplanet. Draft
