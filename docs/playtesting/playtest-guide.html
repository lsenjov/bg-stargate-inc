Setup, observation goals, and feedback prompts.

Before The Test

  1. Record the rules version.
  2. Record player count and player experience.
  3. List components used.
  4. Write the main question for this test.

Observe

  • Where players pause or ask for clarification.
  • Which actions feel obvious or ignored.
  • Whether the network creates interaction.
  • Whether the game ends too early, too late, or flat.
  • Which moments players retell after the game.

Ask Afterward

  • What did you think you were trying to do?
  • When did another player's move matter to you?
  • Which rule was hardest to remember?
  • Which action would you remove?
  • Would you play one more turn?
